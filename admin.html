OE Biolink 管理后台

输入 GitHub Personal Access Token 以授权编辑。Token 仅保存在你本机浏览器，不会上传到任何服务器。

如何生成 Token
  1. GitHub → 右上角头像 → Settings
  2. 左侧最下 Developer settings
  3. Personal access tokens → Tokens (classic)
  4. Generate new token (classic)
  5. Scope 勾选 repo（读写仓库内容）
安全说明：Token 存于本机 localStorage，只有这台电脑能读到。它是「能改数据」的钥匙，别人拿到才能改。
